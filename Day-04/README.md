# Day 4 — DSA Challenge

## Problems Solved

### 1. Top K Frequent Elements — LeetCode #347
**Approach:** Used a HashMap to count frequencies and Bucket Sort to efficiently find the K most frequent elements.

**Time:** O(n)  
**Space:** O(n)

### 2. Invert Binary Tree — LeetCode #226
**Approach:** Used recursion to swap the left and right children and recursively invert both subtrees.

**Time:** O(n)  
**Space:** O(h)

## What I Learned

- Choosing the right data structure can improve efficiency.
- Bucket-based grouping is useful for frequency problems.
- Recursion makes binary tree problems easier to break down.
- Understanding the approach is more important than simply getting an Accepted result.
