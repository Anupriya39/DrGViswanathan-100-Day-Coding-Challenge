## Problems Solved

### 1. Two Sum – LeetCode #1

- **Difficulty:** Easy
- **Topic:** Array, HashMap
- **Approach:** Used a HashMap to store previously visited elements and their indices. For each element, searched for its complement (`target - nums[i]`).

**Complexity:**
- Time: O(n)
- Space: O(n)

**Key Learning:** Efficient searching using HashMap and complement-based problem solving.
