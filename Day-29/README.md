## 🟢 Problem 1: Counting Valleys

**Platform:** HackerRank

### Approach
I maintained a `level` variable to track the current altitude.

- `U` increases the level by 1.
- `D` decreases the level by 1.
- Whenever an `U` step brings the level back to `0`, it means a valley has been completed.

### What I Learned
- Tracking state while traversing a string.
- Using simple conditions to identify patterns.
- Converting a real-world problem into a simple counting approach.

### Complexity
- **Time:** O(n)
- **Space:** O(1)

## 🟢 Problem 2: Best Time to Buy and Sell Stock II

**Platform:** LeetCode  
**Problem:** #122

### Approach
Used a **greedy approach**.

For every pair of consecutive prices, if the current price is greater than the previous price, I add the difference to the total profit.

This captures every profitable increase without needing to explicitly track buy and sell transactions.

### What I Learned
- Understanding greedy problem-solving.
- Identifying when local profitable choices can be combined.
- Improving array traversal and optimization skills.

### Complexity
- **Time:** O(n)
- **Space:** O(1)
