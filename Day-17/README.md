## LeetCode Problems Solved

### 1. Merge Two Sorted Lists - LeetCode #21

**Difficulty:** Easy

### Approach
Used a dummy node and two pointers to compare the values of both sorted linked lists. The smaller node is added to the merged list, and the remaining nodes are attached at the end.

### Complexity
- Time: O(n + m)
- Space: O(1)

---

### 2. Kth Smallest Element in a BST - LeetCode #230

**Difficulty:** Medium

### Approach
Used iterative Inorder Traversal with a Stack. Since an inorder traversal of a Binary Search Tree visits nodes in ascending order, the kth visited node gives the kth smallest element.

### Complexity
- Time: O(H + k)
- Space: O(H)
