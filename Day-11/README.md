# Day 11 – Balanced Binary Tree & 3Sum

## Problems Solved

### 1. Balanced Binary Tree – LeetCode #110
- Approach: Recursive height calculation
- Time Complexity: O(n)
- Space Complexity: O(h)

### 2. 3Sum – LeetCode #15
- Approach: Sorting + Two Pointers
- Time Complexity: O(n²)
- Space Complexity: O(1) extra space (excluding sorting/output)

## Key Learnings

- Practiced recursive tree traversal.
- Learned to detect imbalance efficiently using a sentinel value.
- Strengthened the Two Pointer technique.
- Learned how sorting helps handle duplicates and optimize array problems.
