# Day 44 — 100 Days of Coding Challenge

## LeetCode #42: Trapping Rain Water

- **Difficulty:** Hard
- **Topics:** Arrays, Two Pointers
- **Language:** Java
- **Status:** Accepted

### Approach
Used two pointers, `left` and `right`, along with `leftMax` and `rightMax` to track the tallest bars encountered from both sides.

At each step, processed the side with the smaller height. If the current bar was shorter than its corresponding maximum, added the difference to the trapped water; otherwise, updated the maximum height.

### Complexity
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

### Key Learnings
- Applied the Two-Pointer technique to an array problem.
- Understood how boundaries determine the amount of trapped water.
- Practiced optimizing time and auxiliary space complexity.
