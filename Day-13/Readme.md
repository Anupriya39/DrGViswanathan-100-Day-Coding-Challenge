Day 13 – Binary Search & Linked List Cycle

Continuing my 100-Day Coding Challenge with two more LeetCode problems in Java. 💻

🧩 Problems Solved
1. Binary Search – LeetCode #704

Approach:
Used the Binary Search technique on a sorted array. The search space is repeatedly divided into half until the target is found or the search space becomes empty.

Time Complexity: O(log n)
Space Complexity: O(1)

2. Linked List Cycle – LeetCode #141

Approach:
Used Floyd’s Cycle Detection Algorithm with two pointers:

slow moves one step at a time.
fast moves two steps at a time.
If they meet, a cycle exists.

Time Complexity: O(n)
Space Complexity: O(1)

📚 What I Learned
Binary Search helps reduce the search space efficiently.
The slow and fast pointer technique is useful for linked-list problems.
Choosing the right algorithm can significantly improve time and space efficiency.
Practicing different DSA patterns helps build stronger problem-solving skills.
