# Day 75 – 100 Days of Code Challenge

## LeetCode Problems Solved

### 1. Add Two Numbers
- **Problem Number:** 2
- **Difficulty:** Medium
- **Topic:** Linked List, Mathematics
- **Approach:** Traverse both linked lists, add corresponding digits along with carry, and construct the result using a dummy node.
- **Time Complexity:** O(max(m, n))
- **Space Complexity:** O(max(m, n))

### 2. Excel Sheet Column Title
- **Problem Number:** 168
- **Difficulty:** Easy
- **Topic:** Mathematics, String
- **Approach:** Convert the column number into its Excel alphabet representation using modulo 26, division, and reverse the resulting string.
- **Time Complexity:** O(log₂₆ n)
- **Space Complexity:** O(log₂₆ n)

## Key Learnings
- Linked list traversal and manipulation.
- Handling carry in mathematical operations.
- Number-to-string conversion.
- Base-26 representation and modulo operations.
- Improving problem-solving and implementation skills in Java.
