## LeetCode #392 - Is Subsequence

**Difficulty:** Easy

### Approach

Used the Two-Pointer approach to check whether string `s` is a subsequence of string `t`.

The pointer for `t` moves through the string, while the pointer for `s` moves forward only when matching characters are found.

### Complexity

- Time: O(n)
- Space: O(1)

### What I Learned

- How to apply the Two-Pointer technique to strings.
- A subsequence maintains the relative order of characters.
- Efficient solutions can often be achieved without using extra data structures.
