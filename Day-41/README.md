This repository contains my Java solutions for two LeetCode problems completed as part of my 100-Day Coding Challenge.

## Problems Solved

### 1. Perfect Squares — LeetCode #279
- **Difficulty:** Medium
- **Topic:** Dynamic Programming
- **Approach:** Used a DP array where `dp[i]` stores the minimum number of perfect squares required to form `i`. For every value, considered all possible perfect squares and selected the minimum count.
- **Key Learning:** Applying dynamic programming to optimization problems and building solutions from previously computed results.
- **Problem:** https://leetcode.com/problems/perfect-squares/

### 2. Minimum Window Substring — LeetCode #76
- **Difficulty:** Hard
- **Topics:** Sliding Window, String, Frequency Counting
- **Approach:** Used a variable-size sliding window and a character frequency array to track the required characters. Expanded the window until all characters were covered, then contracted it to find the minimum-length valid substring.
- **Key Learning:** Handling duplicate characters, maintaining window conditions, and optimizing substring searches.
- **Problem:** https://leetcode.com/problems/minimum-window-substring/
