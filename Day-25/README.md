## Problems Solved

### 1. Validate Binary Search Tree - LeetCode #98

**Approach:**  
Used recursion with a valid range for each node. Every node must be strictly greater than the minimum value and strictly smaller than the maximum value allowed for its position.

**Time Complexity:** O(n)

**Space Complexity:** O(h), where h is the height of the tree.

---

### 2. Middle of the Linked List - LeetCode #876

**Approach:**  
Used the Slow and Fast Pointer technique. The slow pointer moves one step while the fast pointer moves two steps. When fast reaches the end, slow points to the middle node.

**Time Complexity:** O(n)

**Space Complexity:** O(1)
