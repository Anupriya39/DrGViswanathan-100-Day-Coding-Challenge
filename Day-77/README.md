## LeetCode Problems

### 1. Sum of Square Numbers

- **Problem Number:** 633
- **Difficulty:** Medium
- **Topic:** Math, Two Pointers
- **Language:** Java

**Approach:**
- Initialize two pointers: left = 0 and right = sqrt(c).
- Calculate the sum of their squares.
- If the sum equals c, return true.
- If the sum is smaller, increment left; otherwise, decrement right.

**Complexity Analysis:**
- Time Complexity: O(√c)
- Space Complexity: O(1)

**Key Learnings:**
- Two Pointers technique.
- Mathematical problem-solving.
- Handling large integer values.

### 2. Min Stack

- **Problem Number:** 155
- **Difficulty:** Medium
- **Topic:** Stack, Design
- **Language:** Java

**Approach:**
- Used two stacks: one for storing elements and another for tracking minimum values.
- Updated both stacks during push and pop operations.
- Retrieved the minimum directly from the top of minStack.

**Complexity Analysis:**
- Time Complexity: O(1) per operation
- Space Complexity: O(n)

**Key Learnings:**
- Stack implementation and design.
- Auxiliary stack technique.
- Maintaining minimum values efficiently.
