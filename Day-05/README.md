## 📈 Best Time to Buy and Sell Stock — LeetCode #121

### Problem

Given an array of stock prices where `prices[i]` represents the price on the `i-th` day, find the maximum profit possible by choosing one day to buy and a different future day to sell.

If no profit is possible, return `0`.

### Approach

I used a **Greedy Approach**.

- Keep track of the **minimum price** seen so far.
- For each price, calculate the profit if we sell on that day.
- Keep updating the **maximum profit**.
- Since we only need one pass through the array, the solution is efficient.

**Input:**

[7,1,5,3,6,4]
