## Problems Solved

### 1. Insert Greatest Common Divisors in Linked List
- **LeetCode:** #2807
- **Difficulty:** Medium
- **Topic:** Linked List, Mathematics, GCD
- **Approach:**
  - Traverse the linked list.
  - Calculate the GCD of every pair of adjacent nodes using the Euclidean Algorithm.
  - Insert a new node containing the GCD between them.
- **Time Complexity:** O(n log M)
- **Auxiliary Space Complexity:** O(1)

### 2. Count Odd Numbers in an Interval Range
- **LeetCode:** #1523
- **Difficulty:** Easy
- **Topic:** Mathematics
- **Approach:**
  - Use a mathematical formula to count odd numbers in an inclusive interval.
  - Avoid unnecessary iteration.
- **Time Complexity:** O(1)
- **Space Complexity:** O(1)

## Key Learnings
