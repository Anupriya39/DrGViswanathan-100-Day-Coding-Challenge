# Day 43 — 100 Days of Coding Challenge

## LeetCode Problems

### 1. Word Search II — Problem #212
- **Difficulty:** Hard
- **Topics:** Trie, DFS, Backtracking
- **Approach:** Build a Trie from the given words and use DFS with backtracking to search for words on the board. Trie prefix checking helps prune unnecessary searches.
- **Time Complexity:** Worst case depends on the board dimensions and word prefixes explored.
- **Space Complexity:** O(total characters in all words) for the Trie, plus recursion space.

### 2. Jump Game — Problem #55
- **Difficulty:** Medium
- **Topics:** Greedy, Arrays
- **Approach:** Track the farthest reachable index while traversing the array. If an index is unreachable, return false; otherwise, determine whether the last index can be reached.
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)
