### 1. Contains Duplicate – LeetCode #217
**Difficulty:** Easy

**Approach:**

**Complexity:**
- Time: O(n) expected
- Space: O(n)

### 2. Implement Queue using Stacks – LeetCode #232
**Difficulty:** Easy

**Approach:**
- Used two stacks: `input` and `output`.
- Pushed incoming elements into the input stack.
- Transferred elements to the output stack when it was empty.
- Implemented FIFO operations using two stacks.

**Complexity:**
- Push: O(1)
- Pop: O(1) amortized
- Peek: O(1) amortized
- Empty: O(1)
- Space: O(n)
