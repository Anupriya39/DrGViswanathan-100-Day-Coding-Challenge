# Day 76 – 100 Days of Code Challenge

## LeetCode Problem: Delete Node in a Linked List

- **Problem Number:** 237
- **Difficulty:** Medium
- **Topic:** Linked List
- **Language:** Java

### Approach
1. Copy the value of the next node into the given node.
2. Update the next pointer to skip the next node.
3. This effectively removes the given node without accessing the head.

### Complexity Analysis
- **Time Complexity:** O(1)
- **Space Complexity:** O(1)

### Key Learnings
- Linked list node manipulation.
- Understanding references and next pointers.
- In-place deletion without head access.
- Constant-time operations with O(1) extra space.
