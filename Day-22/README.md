### 🧩 Problem: Island Perimeter

* **LeetCode:** [#463 - Island Perimeter](https://leetcode.com/problems/island-perimeter/)
* **Difficulty:** Easy
* **Language:** Java
* **Status:** Accepted ✅

### 💡 Approach

Traversed the 2D grid and counted 4 sides for every land cell. For each shared side with the land cell above or to the left, subtracted 2 from the perimeter to avoid double-counting.

### 📚 What I Learned

* 2D array traversal
* Grid-based problem-solving
* Calculating perimeter using shared boundaries
* Avoiding unnecessary extra space

### ⏱️ Complexity Analysis

* **Time Complexity:** O(m × n) — Traverse each cell once.
* **Space Complexity:** O(1) — Uses constant extra space.
