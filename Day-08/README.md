## LeetCode #206 — Reverse Linked List

### 🧩 Problem
Given the head of a singly linked list, reverse the list and return the reversed list.

### 💡 Approach 

Used an **iterative approach** with three pointers:

- `prev` — keeps track of the previous node
- `current` — points to the current node
- `next` — temporarily stores the next node

At each step, the direction of `current.next` is reversed, and the pointers are moved forward.

### ⏱️ Complexity

- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(1)`

### 📚 What I Learned

- Understanding pointer manipulation in Linked Lists.
- Why we need to save the `next` node before changing links.
- How an iterative approach can reverse a linked list efficiently.
