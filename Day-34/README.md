## 🧩 Problems Solved

### 1. 91. Decode Ways

**Difficulty:** Medium  
**Language:** Java  
**Concept:** Dynamic Programming

### Approach

Used **Dynamic Programming** to calculate the number of possible ways to decode the given string.

For every position:

- Consider the current digit as a single character if it is valid.
- Consider the current and previous digits together if they form a valid number from `10` to `26`.
- Store the number of ways for previously solved positions and build the answer step by step.

### Complexity

- Time: `O(n)`
- Space: `O(n)`
