## Problem Solved

### Remove Duplicates from Sorted List II
- **LeetCode:** #82
- **Difficulty:** Medium
- **Topic:** Linked List
- **Language:** Java

## Approach

1. Create a Dummy Node pointing to the head.
2. Maintain two pointers: `prev` and `curr`.
3. Check whether the current node has duplicates.
4. If duplicates exist, skip all nodes with that value.
5. Otherwise, move `prev` forward.
6. Continue until the entire list is traversed.

## Complexity Analysis

- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

## Key Learnings

- Dummy Node technique.
- Linked list pointer manipulation.
- Removing all occurrences of duplicate values.
- Handling edge cases in sorted linked lists.
- In-place linked list modification.
